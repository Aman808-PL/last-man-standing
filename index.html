One-time setup needed

This app needs a free Firebase database so everyone's picks sync across devices. Takes about 3 minutes:

  1. Go to console.firebase.google.com and create a free project
  2. In the project, click Build → Realtime Database → Create Database (choose test mode)
  3. Click the gear icon → Project settings → scroll to "Your apps" → click the </> web icon → register an app
  4. Copy the firebaseConfig object it gives you
  5. Paste it into this file, replacing the placeholder near the top of the <script> tag, where it says FIREBASE_CONFIG_PLACEHOLDER
  6. Re-upload the file to GitHub Pages

This only needs doing once. After that, every player just opens the page.
